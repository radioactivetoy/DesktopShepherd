# DesktopShepherd 1.0 — Release Candidate 1

The first release candidate for 1.0. Everything planned for 1.0 is in; from here on only fixes
until the final release. Please report anything that looks wrong.

DesktopShepherd puts translucent, frosted-glass boxes on your Windows 11 desktop that hold your
icons, files, folders and small widgets. It stays behind your windows like the desktop itself,
uses about 100 MB of memory and practically no processor time.

## Download

| File | What it is |
|---|---|
| **DesktopShepherd-Setup-1.0.0-rc.1.exe** | Installer. Installs for your user only, no administrator rights. Uninstall from Windows' *Installed apps*. Running it over an older version updates it and keeps your boxes. |
| **DesktopShepherd-Portable-1.0.0-rc.1.zip** | Portable copy. Unzip anywhere and run; all settings stay in a `data` folder next to the program. |

Windows may warn about an *unknown publisher* (the program isn't code-signed yet): choose
**More info → Run anyway**.

If you already run a beta with "Check for new versions" on, it will offer this update by itself.

## New since beta 5

- **Drop shadow** (per box, in *Personalize*): a soft two-layer shadow lifts the box off the
  wallpaper. Clicks pass straight through it. It only uses memory for boxes that have it on.
- **Raised look** (per box): a bevel all round the inside edge — bright on top, softly lit sides,
  darker bottom — plus a gentle sheen, so the glass reads as a raised panel. Costs nothing extra.
- **Widgets stay behind your windows.** Clicking a widget (to type in a note or the to-do list)
  no longer brings it in front of the program you are using.
- **Update check fixed for 1.0:** it now understands beta → release candidate → final, so the
  final 1.0 will be offered to everyone on a release candidate.

## Also new in the 0.2 betas

- **New app icon and logo** (Explorer, Start menu, taskbar, tray, settings windows).
- **Icons like in Explorer:** Ctrl+C / Ctrl+X / Ctrl+V (files copied anywhere paste into the box
  under the mouse), F2 renames right under the icon, Ctrl+A, Delete, Enter.
- **Weather widget redesigned:** Meteocons icons, feels-like, humidity, wind, chance of rain,
  sunrise/sunset, UV, hour-by-hour and 7 days; *Compact*, *Standard* or *Detailed* looks; several
  places.
- **To-do widget redesigned:** round check circles, readable finished tasks, the add field appears
  with a **+** only when you need it.
- **Light or dark menus and settings**, following Windows by default.
- **Adaptive text:** box text turns dark by itself over bright parts of the wallpaper — works with
  wallpaper slideshows (optional, on by default).
- **Quick search** names the right box for items of folder boxes.
- Spanish and Catalan translations; the program follows the Windows language.

## Principles (unchanged)

- **Stability first:** never hooks into Explorer; your desktop icons always come back, even after
  a crash; your layout is saved safely with dated backups.
- **Light:** about 0 % processor use when idle; nothing redraws unless something changed.
- **Private:** no telemetry. Online features (weather, online calendars, update check) only work
  when you turn them on, and send nothing about you.

## Known limitations

- Not code-signed yet (the *unknown publisher* warning).
- Box positions per monitor setup (e.g. laptop alone vs. docked) still need more real-world
  testing.
