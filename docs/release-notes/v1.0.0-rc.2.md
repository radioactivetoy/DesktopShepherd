# DesktopShepherd 1.0 — Release Candidate 2

The second release candidate for 1.0: the result of a full code review (stability, security,
speed and memory). No big new features; many fixes and hardening.

## Download

| File | What it is |
|---|---|
| **DesktopShepherd-Setup-1.0.0-rc.2.exe** | Installer. Installs for your user only, no administrator rights. Uninstall from Windows' *Installed apps*. Running it over an older version updates it and keeps your boxes. |
| **DesktopShepherd-Portable-1.0.0-rc.2.zip** | Portable copy. Unzip anywhere and run; all settings stay in a `data` folder next to the program. |
| **SHA256SUMS.txt** | Checksums of the files above (the built-in updater checks them before installing). |

Windows may warn about an *unknown publisher* (the program isn't code-signed yet): choose
**More info → Run anyway**.

## Changed: the update check now asks first

DesktopShepherd no longer contacts GitHub until you say so. A small note asks once:
*"Check once a day for new versions of DesktopShepherd?"* — **Yes** or **No**. You can change it
any time in DesktopShepherd settings. (If you used a beta, you'll be asked once too.)

## Safer updates

- The updater only accepts the installer from this project's own GitHub releases, with the exact
  file name, and checks it against the published SHA-256 checksums before running it. A file that
  doesn't match is never started.
- It's saved to a fresh folder and run from there; two updates can't run at once.

## Fixes

- **Rename (F2)** keeps the extension's capitals (`Photo.JPG` stays `.JPG`), does nothing when the
  name didn't change, and tells you why when Windows refuses a name.
- **Paste** never drops files into a folder box, where they'd be hidden.
- **Hidden boxes** (other page, "hide all") no longer keep the program awake: processor use stays
  at zero.
- **Drop shadow**: redrawn once you finish resizing (smooth resizing), and faded boxes get a faded
  shadow from the start.
- **Weather** without internet: a short "no connection" note and a retry every few minutes,
  instead of redrawing every 2 seconds.
- **To-do**: the add field stays open after your first task, Esc only clears it while you type in
  it, and **+** closes it again.
- A desktop-menu "New box" click that timed out no longer pops up at the next start.
- A second paste after a cut no longer shows a Windows error.
- "Move to" in the right-click menu is now translated.
- A mouse press can no longer get stuck after a menu or Alt+Tab.

## Stability and privacy

- **Watchdog**: if the program ever freezes, it is restarted automatically within about half a
  minute and your desktop icons come back.
- **Online calendar links** (agenda widget) are no longer copied to OneDrive; each PC keeps its
  own. They are private links, so they stay on the PC.
- **Calendars** that are huge or malformed are cut short instead of using up memory.
- Every download now has an overall time limit.

## Lighter

- Box contents are kept and only rebuilt when something changes; typing in a note no longer
  redraws every box; icons arriving at start are batched; quick search remembers its results.
- Laptop widget checks Wi-Fi and Bluetooth every 30 s (was 5 s); picture frame and wallpaper
  reading use less memory; the drawing pad is cheaper to draw.
- Measured: about 116 MB of memory and practically 0 % processor at idle (supervisor 2 MB).

## Known limitations

- Not code-signed yet (the *unknown publisher* warning).
- Box positions per monitor setup (e.g. laptop alone vs. docked) still need more real-world
  testing.
