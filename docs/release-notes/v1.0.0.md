# DesktopShepherd 1.0

**Tidy, frosted-glass boxes for your Windows 11 desktop — light, private, and safe by design.**

DesktopShepherd puts translucent boxes on your desktop that hold your icons, files, folders and
small widgets. The boxes sit behind your windows like the desktop itself, use about 100 MB of
memory and practically no processor time, never hook into Explorer, and send nothing about you
anywhere.

## Download

| File | What it is |
|---|---|
| **DesktopShepherd-Setup-1.0.0.exe** | Installer. Installs for your user only, no administrator rights. Running it over an older version updates it and keeps your boxes. `--silent` installs without any window. |
| **DesktopShepherd-Portable-1.0.0.zip** | Portable copy. Unzip anywhere and run; settings stay in a `data` folder next to the program. |
| **SHA256SUMS.txt** | Checksums of the files above (the built-in updater checks them before installing). |

Windows may warn about an *unknown publisher* (the program isn't code-signed yet): choose
**More info → Run anyway**. Requires Windows 11.

## What's in 1.0

**Boxes** — real Windows glass, titles, tabs, roll up, pages, folder boxes, an auto-sort box,
snapping, a box shortcut each, multi-monitor (by role or fixed monitor), drop shadow and a raised
look, fading, and text that stays readable on any wallpaper (also with slideshows).

**Icons like in Explorer** — Ctrl+C / X / V (also with files from Explorer), F2 renames right
under the icon, drag between boxes, Windows' own right-click menu, type to jump.

**Quick search** — Ctrl+Shift+Space finds desktop items (and optionally Start menu programs).

**Widgets** — clock (with world clock), sticky note, drawing pad, system monitor (with network
speed), laptop status (with Bluetooth device batteries), now playing (with volume, seek and sound
output), weather (Meteocons icons, several places, three looks), timer / Pomodoro, calendar,
to-do, agenda (online calendars), picture frame and a search box.

**Steps aside** — while a full-screen game or video runs, the boxes on that monitor pause and the
shortcuts are freed; everything pauses while the screen is off or the PC is locked.

**Seven languages** — English, Spanish, Catalan, French, German, Italian, Portuguese (follows
Windows). Light or dark menus and settings.

**Safe** — your desktop icons always come back, even after a crash; a watchdog restarts the
program if it ever freezes; layouts are saved safely with backups; updates are checked against
published checksums and only when you allow it.

## New since 1.0 RC 3

- **Look options** for boxes (right-click a box → *Personalize*), all optional:
  - **Presets:** ready-made looks (Glass, Solid dark, Minimal, Light frost, Accent) and your own
    saved looks.
  - **Header:** tinted band or line, alignment, a symbol or emoji before the title, title colour
    and weight, UPPERCASE, item count, title only when the mouse is over the box.
  - **Effects:** colour fade, a subtle acrylic texture, accent-colour border, lift on hover.
  - **Icons:** compact / normal / roomy, soft backing behind names, bigger icon under the mouse,
    calm icons.
  - **Cancel** in Personalize puts the box back as it was.
- **Widgets:** an accent colour and a text size for each widget (*Widget settings → Look*).
- **Now playing:** the volume slider can control the playing app (e.g. only Apple Music) or the
  whole PC; *Sound output ▸* in the box menu lists your speakers and headphones and switches with
  one click.
- **Language** is chosen from a drop-down list.
- Fixes: clearer names for audio outputs that share a device; Personalize rows with long labels.

## Known limitations

- Not code-signed yet (the *unknown publisher* warning).
- Switching the sound output uses an unofficial Windows method (the same as popular audio tools);
  if Windows refuses, Sound settings open instead.
- Bluetooth devices that don't report their battery to Windows don't show one.

Thanks for trying the betas and release candidates. Ideas and bug reports are welcome as GitHub
issues — and native speakers, suggestions for better wording in your language too.
