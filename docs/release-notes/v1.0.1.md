# DesktopShepherd 1.0.1

A small update to 1.0 for people starting DesktopShepherd for the first time on several monitors.

## Download

| File | What it is |
|---|---|
| **DesktopShepherd-Setup-1.0.1.exe** | Installer. Installs for your user only, no administrator rights. Running it over an older version updates it and keeps your boxes. `--silent` installs without any window. |
| **DesktopShepherd-Portable-1.0.1.zip** | Portable copy. Unzip anywhere and run; settings stay in a `data` folder next to the program. |
| **SHA256SUMS.txt** | Checksums of the files above (the built-in updater checks them before installing). |

Windows may warn about an *unknown publisher* (the program isn't code-signed yet): choose
**More info → Run anyway**. If you have 1.0 with update checks on, it will offer this update.

## Changed

- **First start with several monitors:** desktop icons you had on a second (or third) monitor now
  get their own box on that same monitor ("Desktop 2"), placed near where they were — they no
  longer seem to disappear from that screen. Icons on the main monitor go into the "Apps" and
  "Desktop" boxes as before. (Windows' icon positions are only read, once, on the first start.)
- **Welcome note:** it now says plainly that your desktop icons are in the boxes, nothing was
  moved or deleted, and closing DesktopShepherd brings them back as before.

Nothing changes for people who already use DesktopShepherd: this only affects the very first
start.

See the [1.0 release](https://github.com/radioactivetoy/DesktopShepherd/releases/tag/v1.0.0) for
everything in DesktopShepherd 1.0.
