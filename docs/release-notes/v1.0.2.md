# DesktopShepherd 1.0.2

A small fix-up release.

## Download

| File | What it is |
|---|---|
| **DesktopShepherd-Setup-1.0.2.exe** | Installer. Installs for your user only, no administrator rights. Running it over an older version updates it and keeps your boxes. `--silent` installs without any window. |
| **DesktopShepherd-Portable-1.0.2.zip** | Portable copy. Unzip anywhere and run; settings stay in a `data` folder next to the program. |
| **SHA256SUMS.txt** | Checksums of the files above (the built-in updater checks them before installing). |

Windows may warn about an *unknown publisher* (the program isn't code-signed yet): choose
**More info → Run anyway**. If you have 1.0 or 1.0.1 with update checks on, it will offer this
update.

## Fixed

- **No more location prompt with Laptop status.** Recent Windows 11 versions treat the name of
  your Wi-Fi network as location information, so adding a Laptop status widget made Windows ask
  *"Allow desktopshepherd to access your location?"*. The widget no longer reads the network name:
  it now shows how the PC is connected — **Wired network**, **Wi-Fi** or **Not connected** — with
  the link speed. (If you allowed location access earlier, you can turn it off in Windows Settings
  → Privacy & security → Location; DesktopShepherd doesn't need it.)
- **Desktops connected by cable** no longer show "Wi-Fi: not connected" in Laptop status.
- **Right-click on a widget** always opens the box menu. The clock's *24-hour* option and the
  calendar's *Week starts on Sunday* are in *Widget settings* (your choices are kept).

See the [1.0 release](https://github.com/radioactivetoy/DesktopShepherd/releases/tag/v1.0.0) for
everything in DesktopShepherd 1.0.
