# DesktopShepherd 1.0.3

More control over tabs.

## Download

| File | What it is |
|---|---|
| **DesktopShepherd-Setup-1.0.3.exe** | Installer. Installs for your user only, no administrator rights. Running it over an older version updates it and keeps your boxes. `--silent` installs without any window. |
| **DesktopShepherd-Portable-1.0.3.zip** | Portable copy. Unzip anywhere and run; settings stay in a `data` folder next to the program. |
| **SHA256SUMS.txt** | Checksums of the files above (the built-in updater checks them before installing). |

Windows may warn about an *unknown publisher* (the program isn't code-signed yet): choose
**More info → Run anyway**. If you have 1.0 or later with update checks on, it will offer this
update.

## New

- **Tabs per box.** The tab rules in *Settings → Auto-sort tabs* are now the default. Any
  auto-sort box can have its own tabs instead: *Personalize → Tabs by kind → Tabs just for this
  box*. Switch back to *Use the default tabs* at any time.
- **Folder boxes sorted into tabs.** A folder box (for example Downloads) can split its files into
  tabs by kind — Apps, Files, Archives, Pictures, Folders, Other — with the same rules. Turn it on
  with *Sort into tabs by kind* in the box's right-click menu or in Personalize.
- **Drag to reorder.** Drag a tab along a box to move it (normal boxes too). In the rule lists,
  drag a rule by its handle (≡) to change the order; the order decides the order of the tabs and,
  when a file matches two rules, which one wins.

## Fixed

- The program's own tab names (Apps, Files, Archives, Pictures, Folders, Other, Desktop) now show
  in your language. Tab names you typed stay as you wrote them.
- A folder box with *Collect other desktop items* ticked did nothing; such boxes now use
  *Sort into tabs by kind* automatically.

See the [1.0 release](https://github.com/radioactivetoy/DesktopShepherd/releases/tag/v1.0.0) for
everything in DesktopShepherd 1.0.
