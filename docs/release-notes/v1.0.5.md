# DesktopShepherd 1.0.5

Runs on a brand-new Windows with nothing else installed.

## Download

| File | What it is |
|---|---|
| **DesktopShepherd-Setup-1.0.5.exe** | Installer. Installs for your user only, no administrator rights. Running it over an older version updates it and keeps your boxes. `--install --silent` installs without any window. |
| **DesktopShepherd-Portable-1.0.5.zip** | Portable copy. Unzip anywhere and run; settings stay in a `data` folder next to the program. |
| **SHA256SUMS.txt** | Checksums of the files above (the built-in updater checks them before installing). |

Windows may warn about an *unknown publisher* (the program isn't code-signed yet): choose
**More info → Run anyway**. If you have 1.0 or later with update checks on, it will offer this
update.

## Fixed

- **No more "VCRUNTIME140.dll was not found".** The program needed Microsoft's Visual C++
  runtime, which most PCs have (many apps install it) but a fresh Windows doesn't. On such a PC
  DesktopShepherd couldn't start at all. The few runtime parts it uses are now built into the
  program (it grew by about 0.15 MB); nothing else needs to be installed.

Nothing else changes. See the
[1.0.3 release](https://github.com/radioactivetoy/DesktopShepherd/releases/tag/v1.0.3) for the
latest new features.
